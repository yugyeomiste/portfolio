## Le site

Fait à la main en HTML, CSS et JavaScript, sans framework. Les projets sont décrits dans un seul fichier, [`data/portfolio.json`](data/portfolio.json), et les pages se construisent à partir de lui : ajouter un projet revient à ajouter une entrée dans ce fichier.

Pour le lancer en local :

```bash
python3 server.py
```

puis ouvrir http://localhost:8000.
